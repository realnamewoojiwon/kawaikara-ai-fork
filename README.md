# Kawaikara AI fork

개인과 친구끼리 사용하는 Kawaikara 수정본입니다. 원본: https://github.com/fabyday/kawaikara (v2.3.1). 원본 MIT 라이선스를 유지합니다.

## 실행

1. 배포 ZIP을 모두 풉니다.
2. 폴더 안의 **Kawaikara AI fork.exe**를 실행합니다. 설치와 관리자 권한은 필요하지 않습니다.
3. 서비스 버튼을 누릅니다. 로그인이 필요하면 각 서비스에서 직접 로그인합니다.

원본 아이콘을 사용하는 작은 실행 도우미가 공식 Electron 실행 파일을 엽니다. 화면에도 원본 아이콘을 사용합니다. 내부 electron.exe와 VMP 서명 파일은 수정하지 않습니다.

- F11: 전체화면 켜기/끄기
- Ctrl + Home: 시작 화면
- Tab: 일반적인 버튼/입력칸 이동
- 서비스 메뉴: 홈의 전체 메뉴 버튼 또는 창 위쪽 보기 메뉴

## 변경

### v2.3.1-ai.3 — Chrome 확장 프로그램 수동 추가

홈 화면의 **확장 프로그램** 버튼 또는 위쪽 **확장 프로그램 → 확장 프로그램 관리**를 엽니다.

1. 신뢰하는 Chrome 확장 파일의 압축을 풉니다.
2. **확장 폴더 추가**를 누르고 `manifest.json`이 들어 있는 폴더를 선택합니다.
3. 표시된 요청 권한을 확인하고 추가한 뒤, 서비스 화면을 새로고침합니다.

확장마다 켜기·끄기·다시 불러오기·삭제를 지원합니다. 팝업 또는 설정 페이지를 제공하는 확장은 관리 화면에서 열 수 있으며, 실행 중인 팝업은 위쪽 확장 메뉴에서도 엽니다. 확장은 앱의 `data/extensions/`에 복사하고 다음 실행 전에 자동 복원합니다. 원본 확장 폴더는 수정하거나 삭제하지 않습니다. 확장 파일 변경은 자동 반영되지 않으므로 업데이트하려면 기존 확장을 삭제하고 새 폴더를 추가하세요.

**실험적 지원:** Electron이 지원하는 Chrome 확장 기능 범위만 제공합니다. 테스트 확장의 실제 페이지 조작, MV3 백그라운드 통신, 로컬 저장, 팝업, 설정, 재시작 복원을 확인했습니다. 모든 웹 스토어 확장을 보장하지 않습니다. 웹 스토어의 바로 설치, CRX 파일 직접 추가, 자동 업데이트, Chrome 계정 동기화, 동적인 action 버튼/클릭 동작은 지원하지 않습니다. `activeTab` 권한과 현재 탭을 사용하는 팝업, 네트워크 차단·요청 변경 확장은 일부 작동하지 않을 수 있습니다. 불러오기 성공은 모든 기능의 정상 동작을 뜻하지 않습니다.

쿠팡플레이를 선택한 동안에는 기존 사이트 호환 처리 때문에 `chrome.webRequest` 확장의 네트워크 기능이 충돌할 수 있습니다. 다른 서비스로 전환하면 해당 처리를 해제합니다.

확장은 요청한 사이트의 데이터에 접근할 수 있습니다. 허용된 웹사이트에서만 실행하며, 앱 내부 파일 페이지 접근은 허용하지 않습니다. 관리 화면은 확장이 실행되는 세션과 분리하고, 확장 팝업·설정에는 앱 제어 기능이나 Node.js 접근을 제공하지 않습니다. 사용자 확장, 로그인 및 확장 설정은 배포 ZIP에 넣지 않습니다.

Electron 지원 범위: https://www.electronjs.org/docs/latest/api/extensions

기존 버전에서 업데이트하려면 앱을 종료하고 기존 실행 폴더에 새 배포의 프로그램 파일을 덮어쓰세요. 기존 `data/`는 보존하세요. 새 배포에는 `data/`가 없습니다.

- 사이트가 환경설정이나 프로그램 작업을 실행할 수 있던 연결을 차단했습니다. 실행 요청의 창, 프레임, 주소를 검증합니다.
- 웹페이지를 제한된 권한으로 실행하는 샌드박스를 활성화했습니다.
- 위험한 YouTube 다운로드 실행 기능, 로그인 쿠키의 평문 파일 내보내기, 치지직의 외부 스크립트 자동 실행, Discord 활동 전송을 제거했습니다.
- 외부 링크는 사용자 정보가 붙지 않은 HTTPS 주소만 엽니다.
- 공식 지원 엔진 Electron 43.5.0 / Chromium 150.0.7871.250을 사용합니다. 이 PC에서 44.1.0은 페이지 재열기 충돌이 있어 제외했습니다.
- 자동 업데이트로 원본 설치 파일에 덮어쓰지 않습니다.
- 16개 서비스 버튼에 로컬 로고를 넣었습니다. 크런치롤을 제거했습니다.

## 검증 범위와 한계

서비스 접속 검사는 영상 재생을 차단한 별도 빈 프로필에서 진행합니다. 접속 성공은 로그인·결제·유료 영상 재생 성공을 뜻하지 않습니다. 쿠팡플레이, 티빙, 치지직 영상은 재생하지 않습니다.

Castlabs의 공개 실행 파일은 개발용 VMP 인증을 포함합니다. 유료 서비스가 요구하는 운영용 인증은 별도 서명이 필요할 수 있습니다. Widevine 구성 요소 준비와 테스트용 키 생성만으로 Netflix 등 실제 유료 재생이 보장되지는 않습니다. 막히는 서비스는 버튼의 브라우저로 열기 또는 도움 메뉴를 사용하세요.

설명: https://github.com/castlabs/electron-releases#how-does-it-work

어떤 검사도 악성 코드나 취약점이 전혀 없음을 보장하지 않습니다. 확인한 수정·검사 범위는 VALIDATION.json과 SECURITY.md에 기록합니다.

## 개인정보

로그인·설정·캐시는 앱 폴더의 data/에 보관합니다. 이 폴더는 개인용이므로 GitHub나 배포 ZIP에 넣지 않습니다. 외부 로그인 도우미의 기록도 data/external-login/에만 보관합니다. 로그는 data/logs/에만 저장합니다.

배포에는 원본 로그인 프로필, 쿠키, 비밀번호, 개인 시청 기록, 원본 .git 이력, 인증 파일, 개인 화면 캡처를 포함하지 않습니다. 공개 홈 화면 캡처는 빈 테스트 프로필로 만들었습니다.

친구에게는 릴리스의 배포 ZIP을 공유하세요. 내 PC의 data/가 들어 있는 실행 폴더를 그대로 보내면 로그인 정보도 함께 전달될 수 있습니다. 친구는 자기 계정으로 따로 로그인해야 합니다.

## 소스에서 다시 만들기

Windows x64, Node.js 22.12 이상, pnpm, 기본 Windows .NET Framework C# 컴파일러가 필요합니다.

1. pnpm install --frozen-lockfile --ignore-scripts
2. pnpm build
3. dist/Kawaikara AI fork/Kawaikara AI fork.exe 실행

보안 단위 검사: `pnpm test`. 실제 확장 실행 검사: 빌드 후 `pnpm test:extensions` (화면 표시 가능한 Windows 환경과 example.com 접속 필요). 테스트는 별도의 빈 프로필과 자체 테스트 확장만 사용하며, 유료 서비스 영상은 재생하지 않습니다.

빌드 스크립트는 공식 실행 엔진 ZIP의 SHA-256을 검사하고, 현재 소스를 새 app.asar로 묶습니다. 기존 dist/data는 지우지 않습니다. 소스 압축은 배포 프로그램을 포함하지 않습니다.
